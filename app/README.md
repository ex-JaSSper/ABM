# ABM-сервис — «движок следующего действия»

Интерактивный прототип по ТЗ [`../ABM-service-spec.md`](../ABM-service-spec.md) и схеме процесса `../abm-process-v3.drawio`.

**Статус:** фаза 1 — кликабельный прототип на тестовых данных. Вся доменная логика (движок задач, «Фокус», две агрегации, плоскость гипотез) реализована и работает. Данные хранятся в памяти + `localStorage` браузера. Импорт xlsx/Google-таблиц и Supabase — следующая фаза (модель данных под них уже заложена).

## Стек

React 18 + Vite + TypeScript + Tailwind v4. Роутинг — `react-router-dom` (hash-роутер, чтобы работало и при заливке в любую папку без серверных rewrite-правил). Графиков-библиотек нет: воронка и прогресс-бары нарисованы на CSS.

## Визуальный язык — «Отвес»

Дизайн сделан по скиллу **frontend-design** (выразительный, нешаблонный облик), а не как типовой SaaS-дашборд. Метафора — **чертёжный измерительный прибор**: в спеке первый фильтр называется «первичный отвес», отсюда и название сервиса.

- **Палитра «Ink & Blueprint»** (`src/index.css`, блок `@theme`): чертёжная бумага, тёмный «корпус прибора» blueprint-navy, латунный отвес-сигнал brass (фокус/внимание), signal-red (тревога/зависла), teal — **отдельная плоскость гипотез**. Тёплое = живая воронка, холодное = измерение стратегии: цвет кодирует «две плоскости» из ТЗ.
- **Типографика:** Space Grotesk (дисплей) + IBM Plex Sans (текст) + IBM Plex Mono (все цифры/метрики — как показания прибора). Подключены через Google Fonts в `index.html`; для полностью офлайн-деплоя шрифты можно заселф-хостить (`@fontsource/*`).
- **Сигнатура:** панель «Фокус» нарисована как **отвес** — латунная нить с грузиком, зависшие компании отмечены пульсирующим маячком; воронка — реальная сужающаяся форма.
- Соблюдён «пол качества»: адаптивность, видимый фокус на полях, `prefers-reduced-motion`.

## Структура

```
src/
  types.ts            доменная модель (раздел 4)
  data/mock.ts        тестовые данные (пищепром-база)
  lib/engine.ts       чистая доменная логика: метрики, воронка, фокус, стадии, прогресс гипотез
  store/store.tsx     стор + действия движка (React Context, persist в localStorage)
  components/         Layout, UI-примитивы, модалка завершения задачи
  pages/             Dashboard, Signals, Companies, CompanyPage, Contacts, Tasks, Hypotheses
```

## Как пощупать логику

1. **Сигналы** → «В работу» по новой компании: создаётся задача «Разобрать сигнал», компания уходит в «В работе».
2. Открыть компанию → **Завершить** задачу → модалка предложит назначить следующий шаг (с типом) **или** исключить. Пропустить нельзя — иначе компания всплывёт в «Фокусе».
3. Завершение задачи типа-метрики (касание/встреча/договорённость) даёт `+1` в счётчик на дашборде и двигает стадию воронки.
4. **Фокус** на дашборде: «Мясной двор» висит без шага, «Молочные реки» — с просрочкой. Оба сверху.
5. **Гипотезы**: клик по подзадаче двигает прогресс-бар (независимо от воронки).
6. Сбросить данные к исходным: очистить `localStorage` (ключ `abm-state-v1`) и обновить страницу.
