# Подключение Supabase к ABM-сервису

Пошагово. Пароли/ключи ввожу не я — ты создаёшь проект сам и присылаешь мне **URL** и **anon-ключ** (их можно светить: доступ ограничен политиками RLS).

## 1. Создать проект
1. Зайти на **supabase.com** → Sign in (GitHub/почта) → **New project**.
2. Имя: `abm`, придумать пароль БД (сохрани у себя), регион — ближайший (Frankfurt).
3. Дождаться, пока проект поднимется (~1–2 мин).

## 2. Создать таблицы
1. Слева **SQL Editor** → **New query**.
2. Вставить целиком содержимое [`schema.sql`](schema.sql) → **Run**.
3. Должно выполниться без ошибок. Проверить: слева **Table Editor** → видно 8 таблиц (`strategy`, `hypothesis`, `hyp_task`, `hyp_subtask`, `company`, `contact`, `company_task`, `kpi_target`).

## 3. Взять ключи для приложения
**Project Settings → API**:
- **Project URL** — вида `https://xxxx.supabase.co`
- **anon public** ключ — длинная строка (это публичный ключ, не service_role!).

Пришли мне эти два значения — я пропишу их в приложении.

## 4. Вход в приложение (авторизация)
Схема по умолчанию требует логин (это безопасно). Заведи пользователей:
- **Authentication → Providers → Email**: включить. Для простоты выключить «Confirm email» (на время).
- **Authentication → Users → Add user**: создать 1–5 аккаунтов для команды.

> Хочешь совсем без логина на первое время? В `schema.sql` есть закомментированный блок «ВАРИАНТ БЕЗ ЛОГИНА» — раскомментируй и перезапусти его. Тогда приложение работает по anon-ключу без входа. Но любой, у кого есть ссылка+ключ, получит доступ — так только для быстрой пробы.

## 5. Что дальше делаю я
- Пропишу URL/anon-ключ в конфиг фронтенда (`.env`, ключ безопасно лежит на клиенте).
- Подключу слой данных: чтение всего состояния и запись изменений идут в Supabase (см. пример маппинга в [`api-example.js`](api-example.js)).
- Импорт Excel и «загрузка стратегии» будут писать прямо в базу.
- Реалтайм (по желанию): изменения одного пользователя видны другим без перезагрузки.

## Модель данных (кратко)
```
strategy ─┬─ kpi_target
          └─ hypothesis ─ hyp_task ─ hyp_subtask
company ─ contact
company_task → (company, contact, hypothesis, hyp_task)   -- задача двигает воронку и кормит автотрекинг гипотез
```
Рабочее пространство общее: все залогиненные видят одни и те же данные (мультиарендность в MVP не нужна).

## Бесплатный тариф
Free-tier Supabase: 500 МБ базы, до 2 активных проектов, авторизация и API включены. Для 1–5 пользователей — с большим запасом. Проект «засыпает» после недели простоя — открывается снова при первом заходе.
